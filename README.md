# kali-linux-vm-setup
This repository documents my installation and configuration of a Kali Linux testing environment.

## Environment Details
- *Host OS:* Windows
- *Hypervisor:* Oracle VM VirtualBox (v7.2.16)
- *Guest OS:* Kali Linux (2026.2 VirtualBox Image)

## Setup Steps Completed
1. Downloaded and extracted the pre-built Kali Linux .7z archive using 7-Zip.
2. Installed VirtualBox.
3. Imported the .vbox appliance and successfully booted the machine.
